# FitFlow Redesign

## Redesign of the FitFlow fitness application targeting a unified iOS/Android/Web experience with real-time tracking and AI-personalized workout plans.

## Tech Stack

* **Frontend:** Flutter (Mobile + Web)
* **Backend:** NestJS microservices behind an API Gateway
* **AI Service:** Python / FastAPI
* **Databases:** PostgreSQL (Relational & Health data), MongoDB (Logs & Feed)
* **Cache / Real-time:** Redis
* **Authentication:** Auth0

Refer to the `/docs` directory for the full technology comparison tables, weighted decision matrix, high-level architecture diagram, and `ADR-001` documenting the final stack decision.
